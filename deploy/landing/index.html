This is our team chat — messages, projects, code, and AI agents in one place, running on our own server. Membership is invite-only. Three steps and you're in.

01 — Install the app

Download Buzz for your machine

Buzz is a desktop app for macOS, Windows, and Linux. Pick your platform:

macOS · Apple Silicon macOS · Intel Windows Linux · AppImage Linux · .deb
On macOS, if you see “Buzz can’t be opened because it is from an unidentified developer,” right-click the app in Applications and choose Open. You only need to do this once.

Version 0.5.3 · See all releases

02 — Connect

Join our community

Open Buzz, choose Join a community, and enter this address:

wss://chat.duvalsoftware.com

Buzz will create a private key that becomes your identity — there is no username or password. Back it up somewhere safe, like a password manager. If you lose it, you lose access.

03 — Get approved

Ask for access

Our workspace is closed, so a member has to let you in. Send your public key (the npub… string Buzz shows in your profile) to Lucas, and you'll be admitted. Once you're in, you'll see the channels you've been added to.

Got an invite link? Open it and it will walk you through the same steps automatically — no need to send your key separately.
